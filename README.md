## Setting up electron JS and Node JS!

1. Install nodeJS from the website or through the terminal!
    [[https://nodejs.org/en/download]]
2. Ensure the path has been defined otherwise npm will not be able to be accessesd

3. Clone the git repositry in vs code

4. Access the file and run `npm start` in the vs code terminal- Ideally it is going to say that you dont have electron installed

5. Then type `npm install electron --save-dev` in the vs code terminal

6. Try `npm start` again and it should run!
